# Phase 7: Documenting, Evaluating & Evolving Architecture

A decision no one can find, judge, or change is barely a decision. This phase is
about the architecture that lives *over time*: communicating it so others can build
and remember it (the C4 model and views), capturing decisions durably (ADRs, with
the architect's lens), evaluating a design before and after it's built (scenario
evaluation and fitness functions), designing for change as a first-class
requirement (evolutionary architecture), and modernizing the legacy systems you'll
actually inherit without a doomed big-bang rewrite.
