# Phase 2: Foundations of Structure

Every architecture is, underneath, a set of choices about where the lines go and
which things depend on which. This phase covers the timeless forces that govern
those choices regardless of style or era: coupling and cohesion (and the precise
vocabulary of connascence), how to draw component boundaries that survive change,
using the domain itself as the source of structure (Domain-Driven Design), and a
map of the architectural styles you'll choose among in Phase 3.
